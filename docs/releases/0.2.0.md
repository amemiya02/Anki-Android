# Hayaki 0.2.0

Hayaki on Android, iPhone and iPad now shares a public version. Android users upgrading from `2.26.0alpha14` will see `0.2.0` in About. Android's internal build number advances, so the update installs over the existing Hayaki app with the same signing identity. The Android and iOS build numbers are independent.

- Find Hayaki by its smiling folded-card icon. Choose from ten Themes and set System, Light, Dark or Black Appearance separately.
- On Decks, check today's queues and study one Deck or choose Study All. Close a finished Deck to continue to the next eligible one. Leaving early returns to Decks.
- Reveal and rate Cards in the same thumb area. Finished shows the session's review count, elapsed time and rating distribution alongside the next available action.

Each joint release tag identifies the tested source in its repository. If a fix ships on only one platform, its release notes name that platform and version.

## Android performance

On the same API 35 x86-64 emulator and 100,000-card collection, median cold launch increased from 1,854 ms to 2,003 ms. The p95 frame time for scrolling Browse was 103.86 ms before and 103.85 ms after. Reveal frame p95 changed from 135.01 ms to 133.58 ms. For consecutive ratings, frame p95 changed from 154.00 ms to 157.56 ms, and missed deadlines changed from 334 of 390 frames to 345 of 392. These emulator measurements include renderer and host costs. [Paired reports, per-action samples and traces](https://github.com/amemiya02/Hayaki/actions/runs/44748691056/artifacts/14635237868)
