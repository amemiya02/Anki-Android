# Emulator baselines

Each Hayaki archive contains 97 original Android screenshots and the corresponding accessibility trees. The nine profiles combine English, Simplified Chinese and Japanese with Light, Dark and Black. The file names match the screen states listed in the comparison gallery. The Official App archive holds twenty earlier AnkiDroid 2.25.3 captures for each language. [Before and after gallery](../gallery/README.md)

[The capture index](provenance.csv) records the emulator, APK digest, PNG digest and XML digest for each Hayaki screen. Each archive preserves the screenshot and tree as captured. The final review repeated the changed navigation, sharing, Change Note Type and widget flows. The index identifies the exact APK used for each screen.
