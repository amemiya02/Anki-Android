# Redesign decisions

- **Identity and sharing.** The Fork is Hayaki, with launcher Icon A and a separate Android app ID and collection. Ordinary Android text and file sharing reaches Hayaki. Integrations that target the Official App’s public API still address that installation. [Identity ADR](../../adr/0001-own-fork-no-upstreaming.md) · [Name and icon](../../../.scratch/ankidroid-redesign/issues/06-complete-the-chosen-direction-dark-black-name-and-launcher-i.md)
- **Foundation and themes.** The owner chose Quiet Paper with Newsreader, LXGW WenKai and Klee One, and one Material Symbols style. Light uses the approved Plain paper palette. Prior Plain and E-ink theme selections migrate to Light. The available themes are Light, Dark and Black. [Direction ADR](../../adr/0005-direction-quiet-paper.md) · [Foundation values](../quiet-paper.values.json) · [Palette comparisons](../light-palette/README.md) · [Theme migration](../../../.scratch/ankidroid-redesign/issues/07-foundation-colours-shape-and-the-three-themes.md)
- **Study screen.** The owner chose option A for Deck counts, the study bar and answer buttons. The newer study screen carries the legacy features the owner chose to retain, including the Card Template API, speech, whiteboard saving, Deck title and the remaining time estimate. [Core Loop approval](../../../.scratch/ankidroid-redesign/issues/14-mockups-for-the-core-loop.md) · [Study feature ledger](../core-loop/old-study-screen-features.md)
- **Remaining Mockups.** On 2026-11-18 the owner approved the Mockups, all twelve recommended choices and the revised Light palette. The decision records show the choices for Browse and the note editor, Settings and dialogs, Note Types, sync, first run, widgets and notifications. [Finding and adding](../../../.scratch/ankidroid-redesign/issues/25-mockups-for-finding-and-adding.md) · [Settings and dialogs](../../../.scratch/ankidroid-redesign/issues/32-mockups-for-settings-and-dialogs.md) · [Remaining surfaces](../../../.scratch/ankidroid-redesign/issues/41-mockups-for-the-rest.md)
- **Reporting and distribution.** Automatic crash reports and usage statistics are off. The spec defers distribution, release signing, support and new translations beyond English, Simplified Chinese and Japanese. Existing translations remain available. [Reporting decision](../../../.scratch/ankidroid-redesign/issues/02-switch-off-crash-reports-and-usage-statistics.md) · [Spec scope](../../../.scratch/ankidroid-redesign/spec.md#out-of-scope)
- **Sync.** The server operator sets up the self-hosted endpoint. Hayaki accepts its address and signs in to that server. The owner can also move Deck and collection packages between apps. [Sync setup](../../../.scratch/ankidroid-redesign/issues/44-sync-setup-around-a-self-hosted-server.md) · [Package exchange](round-trip/README.md)
- **Personal sign-off.** On 2026-11-18 the owner asked engineering work to continue and deferred the personal phone walk and sign-off. The sign-off remains open. [Milestone 5 issue](../../../.scratch/ankidroid-redesign/issues/51-milestone-5-sign-off-the-redesign-is-done.md)
