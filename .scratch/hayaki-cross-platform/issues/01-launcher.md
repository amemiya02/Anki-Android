# Recognise Hayaki from launcher to Welcome

Status: ready-for-agent
Type: AFK
User stories: 1, 2, 23

## Parent

[Hayaki 0.2.0 specification](https://github.com/amemiya02/Hayaki/issues/1)

## What to build

Carry the iOS smiling folded-card mark into the Android launcher and Welcome screen. Record the iOS brand revision so maintainers can repeat the import.

## Acceptance criteria

- [ ] On an installed Android build, the adaptive and legacy launcher entries and Welcome show the same mark as iOS.
- [ ] Inspect the eyes, smile and folded corner at launcher size under round and squircle masks and in monochrome mode.
- [ ] The recorded source identifies the icon artwork. A normal Android build uses checked-in assets.
